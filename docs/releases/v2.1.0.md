# RuleScript v2.1.0

RuleScript v2.1.0 lets host applications register several overloads of one host function name.

## Host Function Overloads

Register the same name with different parameter lists, and each registration becomes an overload:

```csharp
engine.RegisterFunction(
    "AddNumber",
    [
        new RuleScriptParameterSymbol("a", RuleScriptValueType.Number),
        new RuleScriptParameterSymbol("b", RuleScriptValueType.Number)
    ],
    RuleScriptValueType.Number,
    args => (decimal)args[0]! + (decimal)args[1]!);

engine.RegisterFunction(
    "AddNumber",
    [
        new RuleScriptParameterSymbol("a", RuleScriptValueType.Number),
        new RuleScriptParameterSymbol("b", RuleScriptValueType.Number),
        new RuleScriptParameterSymbol("c", RuleScriptValueType.Number)
    ],
    RuleScriptValueType.Number,
    args => (decimal)args[0]! + (decimal)args[1]! + (decimal)args[2]!);
```

```rulescript
var two = AddNumber(1, 2);
var three = AddNumber(1, 2, 3);
```

- Calls pick an overload by argument count and argument types, the same way overloads already work for user and built-in functions.
- Registering the same parameter types again replaces only that overload.
- A typed registration replaces an untyped registration of the same name.
- An untyped registration, such as `RegisterFunction(name, args => ...)`, accepts any arguments and replaces every overload of the name.
- Sync and async registrations are tracked separately, so `RegisterFunctionAsync` overloads follow the same rules.
- `RegisterFunctions(host)` registers overloaded `[RuleScriptFunction]` methods as overloads.
- Calls that match no overload report `No matching overload for function 'Name'.` in analysis diagnostics and at runtime.

## Editor Support

Analysis results list every host overload in `HostFunctions` and `Functions`. Signature help shows all overloads and selects the one that fits the current argument position. Hover, completion, and diagnostics also see each overload.

When overloads return different types, the inferred type of a variable assigned from the call is `unknown`.

## New API

- `RuleScriptEngine.UnregisterFunction(string name, IReadOnlyList<RuleScriptValueType> parameterTypes)` removes one overload. `UnregisterFunction(string name)` still removes every overload of the name.

## Behavior Changes

- Registering a name again with a different parameter list now adds an overload instead of replacing the previous registration. Call `UnregisterFunction` first to replace it.
- `RegisterFunctions(host)` throws `NotSupportedException` when two attributed methods map to the same RuleScript signature. For example, `Scale(int)` and `Scale(decimal)` both map to `Scale(number)`. Previously the last method registered replaced the earlier ones.

## Validation

Regression coverage verifies dispatch by argument count and type, async overloads, replacement rules between typed and untyped registrations, removing a single overload, attributed method overloads and signature collisions, analysis symbols and diagnostics, and signature help across overloads.

The core test suite contains 884 tests.
