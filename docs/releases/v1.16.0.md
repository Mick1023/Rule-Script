# RuleScript v1.16.0

RuleScript v1.16.0 adds 26 built-in functions for strings, regular expressions, math, arrays, objects, and dates.

## Strings

| Function | Return | Description |
|---|---|---|
| `IndexOf(value, searchValue)` | `number` | Zero-based index of the first ordinal match, or -1. |
| `LastIndexOf(value, searchValue)` | `number` | Zero-based index of the last ordinal match, or -1. |
| `PadLeft(value, totalWidth)`, `PadLeft(value, totalWidth, padding)` | `string` | Pads on the left with spaces or a single padding character. |
| `PadRight(value, totalWidth)`, `PadRight(value, totalWidth, padding)` | `string` | Pads on the right. |
| `FormatNumber(value, format)` | `string` | Formats with a .NET numeric format string, such as `"0.00"` or `"N0"`, using invariant culture. |

```rulescript
var code = PadLeft(lot.seq, 5, "0");           // "00042"
var weight = FormatNumber(lot.weight, "0.00");   // "12.50"
```

`totalWidth` must be a whole number from 0 to 1,000,000. Use template strings for general text formatting.

## Regular Expressions

| Function | Return | Description |
|---|---|---|
| `RegexIsMatch(value, pattern)` | `bool` | Whether the text contains a match. |
| `RegexMatches(value, pattern)` | `array` | The text of every match. |
| `RegexReplace(value, pattern, replacement)` | `string` | Replaces every match; the replacement can refer to groups as `$1`. |

```rulescript
if RegexIsMatch(lotId, "^LOT-\\d{4}-\\d+$") then:
    var numbers = RegexMatches(lotId, "\\d+");
endif
```

Patterns use .NET regular expression syntax with invariant culture. Remember that `\` must be written as `\\` inside a RuleScript string. Each call may run for at most 1 second, so a catastrophic pattern stops the script with an error instead of hanging it. An invalid pattern also throws.

## Math

| Function | Return | Description |
|---|---|---|
| `Pow(value, power)` | `number` | `value` raised to `power`. |
| `Sqrt(value)` | `number` | Square root; negative values throw. |
| `Sum(values)` | `number` | Sum of an array of numbers; an empty array sums to 0. |
| `Average(values)` | `number` | Average of a non-empty array of numbers. |

`Sum` and `Average` throw when an element is not a number.

## Arrays

| Function | Return | Description |
|---|---|---|
| `ArraySlice(array, start)`, `ArraySlice(array, start, end)` | `array` | New array from `start` up to, but not including, `end`. |
| `ArrayIndexOf(array, value)` | `number` | Index of the first matching value, or -1. |
| `ArrayReverse(array)` | `array` | Reverses in place and returns the same array, like `ArraySort`. |
| `ArrayDistinct(array)` | `array` | New array without duplicates, keeping first occurrences. |

`ArraySlice` throws when the range is outside the array. Values match the same way as `ArrayContains`, so `1` and `1.0` are equal.

## Objects

| Function | Return | Description |
|---|---|---|
| `ObjectRemove(object, key)` | `bool` | Removes a key and returns whether it was present. Read-only objects throw. |
| `ObjectMerge(first, second)` | `object` | New object with the keys of both; keys in `second` win. Neither input changes. |

## Dates

Dates are ISO 8601 strings, so they print, serialize to JSON, and pass to and from the host without a new value type:

| Form | Example | Meaning |
|---|---|---|
| No offset | `2026-10-22T10:30:00` | Host local time |
| `Z` | `2026-10-22T02:30:00Z` | UTC |
| Offset | `2026-10-22T10:30:00+08:00` | Explicit offset |

Date-only (`2026-10-22`) and minute-precision (`2026-10-22T10:30`) input is also accepted. Results keep the input's form, use millisecond precision, and include milliseconds only when they are not zero.

| Function | Return | Description |
|---|---|---|
| `Now()` | `string` | Host local date and time, without an offset. |
| `UtcNow()` | `string` | Current UTC date and time, ending in `Z`. |
| `Today()` | `string` | Host local date, such as `2026-10-22`. |
| `DateAdd(date, amount, unit)` | `string` | Adds `year`, `month`, `day`, `hour`, `minute`, `second`, or `millisecond`. `year` and `month` need whole amounts. |
| `DateDiff(start, end, unit)` | `number` | `end - start` in `day`, `hour`, `minute`, `second`, or `millisecond`, including fractions. |
| `DatePart(date, part)` | `number` | `year`, `month`, `day`, `hour`, `minute`, `second`, `millisecond`, `dayOfWeek` (0 is Sunday), or `dayOfYear`. |
| `FormatDate(date, format)` | `string` | Formats with a .NET date format string, using invariant culture. |
| `ParseDate(value)` | `string` | Validates an ISO 8601 date and returns it normalized. |
| `ParseDate(value, format)` | `string` | Parses text in a .NET date format and returns ISO 8601 text. |

```rulescript
var due = DateAdd(lot.arrivedAt, 2, "hour");
if DateDiff(Now(), due, "minute") < 30 then:
    Print(`Lot ${lot.id} is due at ${FormatDate(due, "HH:mm")}`);
endif

var shipped = ParseDate("2026/10/22 09:05", "yyyy/MM/dd HH:mm");   // "2026-10-22T09:05:00"
```

- Compare dates with `DateDiff`, not `<` or `>`.
- Two dates without an offset are compared by wall clock. When either date has `Z` or an offset, a date without one is read in the host's time zone.
- Date functions also accept `DateTime` and `DateTimeOffset` values from the host.
- Other text, such as `10/22/2026`, throws; use `ParseDate(value, format)` to read it.

## Compatibility

The parameters of every new built-in are declared as `any`. Overload resolution therefore prefers an existing user function or Host Function with the same name and argument count, whether it is untyped or its parameter types match, so existing scripts keep calling their own `Sum`, `Now`, or `DateAdd`. Arguments are still validated when the built-in runs. Built-ins from earlier versions are unchanged.

`RuleScriptAnalysisResult.Functions` lists both overloads of `PadLeft`, `PadRight`, `ArraySlice`, and `ParseDate`.

## Validation

Regression coverage verifies results and error messages for every new function, including ordinal search, padding limits, invariant number and date formatting, JSON decimal precision, regex groups, invalid patterns, and timeouts, in-place versus new-array behavior, read-only objects, date forms, offsets, local-time comparison, calendar month arithmetic, host `DateTime` values, and that untyped user and Host Functions with the same names still win.

The core test suite contains 833 tests.
