# RuleScript v1.14.0

RuleScript v1.14.0 adds a safe rename API for editor integrations.

## Rename

`RuleScriptLanguageService.PrepareRename` checks whether the symbol at a 1-based position can be renamed, and `RuleScriptLanguageService.Rename` computes the edits:

```csharp
var prepare = RuleScriptLanguageService.PrepareRename(document, line, column);
if (!prepare.CanRename)
{
    Console.WriteLine(prepare.RejectReason);
    return;
}

var result = RuleScriptLanguageService.Rename(document, line, column, "total");
if (result.Success)
{
    foreach (var range in result.Edits)
    {
        // Replace each range with result.NewName. A null range.File means the analyzed document.
    }
}
else
{
    Console.WriteLine(result.ErrorMessage);
}
```

Variables, parameters, `foreach` loop variables, and functions declared in the document can be renamed. A rename is rejected with a message when:

- the symbol is a built-in or Host Function
- the symbol is exported, or declared in an imported file, because other files may use it
- the new name is not a valid identifier, is a keyword, or is `global`
- a variable, parameter, function, or import alias with the new name already exists
- after applying the edits, the new name would not resolve to exactly the same occurrences

Renaming a symbol to its current name succeeds with no edits.

`PrepareRename` returns a `RuleScriptPrepareRenameResult` with `CanRename`, `RejectReason`, the current `Name`, and the `Range` of the occurrence at the position. `Rename` returns a `RuleScriptRenameResult` with `Success`, `ErrorMessage`, `Edits`, and `NewName`.

## Compatibility

No existing public APIs change. Script execution, analysis diagnostics, and formatting output are unchanged.

## Validation

Regression coverage verifies renaming variables, functions, parameters, and loop variables; renaming to the same name; and rejection of invalid names, keywords, names in use, built-in and Host Functions, exported symbols, and symbols declared in imported files.

The core test suite contains 706 tests.
