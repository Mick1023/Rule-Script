# RuleScript v1.10.2

RuleScript v1.10.2 makes missing parameter type annotation warnings consistent across user functions, including functions with no return statement or declared return type.

## Parameter Type Diagnostics

Previously, analysis warned about untyped parameters only when the function declared a return type. Analysis now reports a warning for every function with untyped parameters. For example:

```rulescript
function Test(a):
endfunction
```

Reports:

```text
Function 'Test' parameter 'a' has no declared type. Consider adding a parameter type annotation.
```

Warnings list only the parameters that are missing type annotations. Explicit annotations such as `a: number` or `a: any` satisfy this check.

These diagnostics remain warnings, so existing untyped scripts continue to execute. Typed parameters continue to reject mismatched arguments during analysis and execution, regardless of whether the function contains a return statement. No public API changes are introduced.

## Validation

Regression coverage verifies that functions without a return statement warn about untyped parameters and reject mismatched arguments when a parameter type is declared.

The complete test suite contains 645 tests.
