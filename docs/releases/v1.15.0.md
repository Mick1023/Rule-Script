# RuleScript v1.15.0

RuleScript v1.15.0 adds conditional expressions, compound assignment, template strings, and a `Range` built-in for counting loops.

## Conditional Expressions

`condition ? whenTrue : whenFalse` selects a value without an `if` block:

```rulescript
var label = count == 1 ? "item" : "items";
var size = weight > 100 ? "large" : weight > 10 ? "medium" : "small";
```

- The condition must be a bool, like an `if` condition. Analysis reports a type mismatch, and execution throws otherwise.
- Only the selected branch is evaluated.
- The operator has the lowest precedence and is right-associative, so `a ?? b ? c : d` means `(a ?? b) ? c : d`.
- Analysis infers the result type from both branches. `flag ? "a" : null` is a nullable string.

## Compound Assignment

`+=`, `-=`, `*=`, `/=`, and `%=` update a variable, `global.` variable, property, or array element:

```rulescript
total += amount;
counter.hits += 1;
totals[index] -= refund;
global.processed += 1;
text += "!";
```

`x += y` behaves like `x = x + y`, including string concatenation for `+=`. Subexpressions of the target, such as the index in `items[NextIndex()] += 1`, are evaluated once. The variable must already exist; assigning to a constant is reported by analysis and fails at runtime.

## Template Strings

Backtick strings interpolate expressions with `${...}`:

```rulescript
var message = `Lot ${lot.id} arrived at ${port.name} (${lot.qty * 2} units)`;
```

- Values are converted to text the same way as string `+`: `null` becomes empty text, numbers use invariant formatting, and booleans are `true` or `false`.
- `\`` writes a backtick and `\$` writes a dollar sign. The escapes from double-quoted strings (`\"`, `\\`, `\n`, `\r`, `\t`) also work. A `$` not followed by `{` is literal text.
- Substitutions can contain any expression, including object literals and nested template strings.
- Like double-quoted strings, template strings must end on the line where they start.

Editor features work inside substitutions: definition, references, rename, hover, and completion see the expressions in `${...}`, while the template text is treated as a string.

## `Range`

`Range(start, end)` and `Range(start, end, step)` return the integers from `start` up to, but not including, `end`. Use them with `foreach` for counting loops:

```rulescript
foreach i in Range(1, 11):
    total += i;
endforeach

foreach i in Range(10, -1, -2):   // 10, 8, 6, 4, 2, 0
    Print(i);
endforeach
```

Arguments must be integers, and `step` cannot be 0. `Range` returns at most 1,000,000 items; larger ranges throw. Loops over a range still follow `MaxLoopIterations`.

## Formatting

The formatter spaces `?`, `:`, and the compound operators, and writes template text verbatim:

```rulescript
var a = flag ? 1 : 2;
total += a;
var text = `a ${a + 1} b`;
```

## Behavior Changes

- `Range` is a new built-in function. Overload resolution prefers exact type matches over `any`, as it already does for built-ins such as `Max`. A script that defines its own **untyped** `Range(a, b)` function, or a host that registers an **untyped** `Range` Host Function, now calls the built-in for two-argument calls. Typed definitions, and calls with other argument counts, are unaffected. Rename such functions or add parameter types to keep calling them.
- `RuleScriptAnalysisResult.Functions` lists both `Range` overloads. The compatibility projection `BuiltinFunctions` keeps one entry per name.

Every other change is additive: `?` alone, backticks, and the compound operators were syntax errors before, so no existing valid script changes meaning.

## New Public API

- AST: `ConditionalExpression`, `TemplateStringExpression`, `CompoundAssignmentStatement`
- `TokenType`: `Question`, `PlusAssign`, `MinusAssign`, `StarAssign`, `SlashAssign`, `PercentAssign`, `TemplateHead`, `TemplateMiddle`, `TemplateTail`, appended after the existing members so their numeric values are unchanged

## Validation

Regression coverage verifies conditional evaluation, associativity, precedence, short-circuiting, and analysis; every compound operator on variables, properties, array elements, and globals, single evaluation of target subexpressions, readonly and type diagnostics; template interpolation, nesting, escapes, unterminated templates, and editor navigation, rename, and completion inside substitutions; `Range` results, limits, and overload signature help; formatter output and round-tripping; and the asynchronous execution path.

The core test suite contains 745 tests.
